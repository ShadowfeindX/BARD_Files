# Decision record

The record of settled decisions: R's rulings of 2026-10-20 and later, and D's rulings of 2026-10-22 and later, each with its id, date and short rationale. The chapters describe the resulting design only, without ids, dates or attributions; this file holds each id (P10c, F2, R-A1 and so on) with its date, wording, reasons and rejected alternatives, and each row links to the chapter heading where the behavior is now described. What is still open is in [09-open-decisions.md](09-open-decisions.md) and [10-waiting-on-d.md](10-waiting-on-d.md).

Package versions below were re-checked on 2026-10-20 [V-28]–[V-35]. Standing rule (F5): re-verify each package's version and platforms on pub.dev right before it enters a pubspec, and pin exact versions where deterministic behaviour matters (`xrandom`, `sembast`, `hive`).
