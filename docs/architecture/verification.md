## Not verified (stated as design or deferred)

- Exact API for minting Firebase custom tokens from a Dart Cloud Function (badge sign-in): `firebase_admin_sdk` provides `createCustomToken` per the investigation [V-24][U]; the full flow on Windows/Linux is probe 8.3.
- How Flutter bundles assets from a workspace package (`content_core`). Deferred to scaffolding.
- Firestore per-document write-rate limits. The design avoids hot documents (new document per batch) so it does not depend on the figure.
- Typst invocation on each platform. Future work.
